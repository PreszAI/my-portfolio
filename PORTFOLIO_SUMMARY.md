**Challenge**: How to use AI APIs without exposing keys?

**Solution**: Server-side API routes keep keys secure.

**Demonstrates**: Understanding of security best practices, not just "make it work."

### 3. Iterative Prompt Engineering

**Process**:
1. Started with basic prompt (~70% accuracy)
2. Created test suite with 10+ diverse incidents
3. Identified failures and edge cases
4. Refined prompts systematically
5. Achieved 90%+ accuracy

**Demonstrates**: Systematic approach to improving AI performance, not just "hope it works."

### 4. Comprehensive Error Handling

**Features**:
- Handles network errors, rate limits, service unavailable
- Fallback analysis when AI unavailable
- User-friendly error messages
- Graceful degradation

**Demonstrates**: Production thinking—what happens when things go wrong?

**Backend**:

- Response processing

**Demonstrates**: Full-stack capabilities, not just frontend or backend.
